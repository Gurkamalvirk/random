# Gurkamal Singh — Portfolio

Personal developer portfolio for **Gurkamal Singh (@Gurkamalvirk)**.

Built with React + Vite and designed around a modern terminal/developer aesthetic.

## Included
- Responsive hero section
- About section
- Featured GitHub projects
- Skills/toolkit
- Education
- Contact links
- Resume link

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
